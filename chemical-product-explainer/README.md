# 化学产品科普视频 SKILL 使用说明

本技能以实验室试剂介绍与科普为主，兼容其他化工产品。根据产品资料策划单人口播或旁白视频，先确认创作方向，再交付完整文字方案。

技能规则见同目录的 [SKILL.md](./SKILL.md)。

## 1. 如何调用

### 在能够访问仓库的会话中

复制以下指令，替换产品和资料：

```text
请读取并使用仓库 liwuso-coder/WSY-video-01 中的
chemical-product-explainer/SKILL.md。

为“尿素”策划一条实验室试剂科普视频。
产品资料：［附标签图片、具体货号、厂家链接或产品文件］
目标平台：抖音
制作条件：单人口播，配产品实拍，低成本。
时长：请根据内容推荐。

请主动检索权威资料，核验产品信息。
先提出 2—3 个候选方向，推荐其中一个并说明取舍，
等我确认后再输出完整交付。
```

仓库为私有仓库时，使用工具必须具有相应访问权限。仅发送仓库链接不保证工具能够读取。

### 在无法访问仓库的会话中

1. 从仓库下载本目录的 SKILL.md。
2. 将文件作为附件上传，或把文件全文粘贴到支持读取长文档的对话中。
3. 发送：“请按附件 SKILL.md 执行，为［产品名称］设计科普视频”，并补充产品资料。

保存到 GitHub 不等于已自动安装。本文提供的是显式读取文件的调用方法；原生技能安装与自动发现方式取决于所使用工具。

## 2. 需要提供什么

最简输入为产品名称；若无法唯一确定化学身份，技能会先询问。建议尽量提供具体商品资料，以便准确制作产品信息卡。

| 输入 | 建议内容 |
|---|---|
| 产品身份 | 名称、品牌、货号、等级／含量、形态 |
| 产品资料 | 清晰标签图片、厂家产品页、说明书、COA 或 SDS |
| 参考材料 | 原视频、现有脚本、字幕、风格参考，可不提供 |
| 视频目标 | 产品认知、知识普及、储存提醒等 |
| 平台与受众 | 发布平台、观众知识基础 |
| 制作条件 | 出镜人数、现有场地、可用素材、预算 |
| 时长与保留项 | 目标时长、必须保留的事实或画面 |

没有原视频也可以使用。没有制作条件时，默认低成本、少人物、少场景；没有指定时长时，由技能推荐。缺失参数不会被自行编造。

## 3. 实际使用流程

### 第一步：提交需求

提供产品名称及已有资料。有原视频时，技能先简短诊断；没有原视频时，直接梳理已有信息。

### 第二步：查看并选择方向

技能会集中提交：

- 推断的视频目标、受众和必须保留的信息。
- 产品信息卡、资料缺口、制作假设及推荐时长。
- 2—3 个有实质差异的候选方向。
- 推荐方向及其创意效果、制作可行性和取舍。

此处会暂停等待确认。影响真实性或故事方向的关键缺口，可能在提出方向前询问。

可以这样回复：

```text
采用方向一，时长控制在 60 秒左右。
单人出镜，只用现有实验室和产品实拍。
其余目标、保留项和制作假设按你的建议执行。
请继续完成全部交付。
```

也可以指定调整，例如“保留方向二的开场，主体采用方向一，请先更新方向供我确认”。

### 第三步：获取完整交付

方向确认后，连续输出以下五项，不再等待大纲审批：

| 交付 | 用途 |
|---|---|
| 情节大纲 | 查看整体思路、内容顺序、推进方式和结尾 |
| 时间线安排与说明 | 查看各段预计时间、画面内容、展示信息和编排目的 |
| 可拍摄脚本 | 按场景执行拍摄，包含主体动作、完整台词、字幕和必要镜头建议 |
| 独立完整口播稿 | 直接录制，整篇连贯，不混入时间戳、镜头指令或分析说明 |
| 资料核验表 | 追溯信息来源、适用产品、核验状态及分歧 |

默认交付策划与文字，不自动生成图片或视频成片。

## 4. 产品信息如何呈现

产品信息卡保留八项，口播只介绍其中四项：

| 字段 | 卡片展示 | 口播介绍 |
|---|---|---|
| 产品名称 | 是 | 是 |
| CAS 号 | 是 | 是 |
| 分子式 | 是 | 是 |
| 常见应用范围 | 是 | 是，仅大类名称 |
| 品牌 | 是 | 否 |
| 等级／含量 | 是 | 否 |
| 包装规格 | 是 | 否 |
| 分子量 | 是 | 否 |

口播四项的顺序可以调整，但不能遗漏。卡片缺失字段标注“未提供／待核实”。

“常见应用范围”只列大类，例如“实验室研究与分析、农业肥料”等，不展开具体实验、作用机制或操作步骤。类目须按产品核验，不把示例作为固定清单，也不暗示不同等级可以直接互换。

别名、外观、储存条件与安全信息不放入产品信息卡，可在后续科普中按需介绍。

## 5. 默认视频组织方式

开场 → 产品核心信息四项 → 外观与性质 → 储存与安全 → 结尾。

可以按产品特点调整：

- 开场可直接点名，也可从相关问题或应用场景切入。
- 默认单人介绍，必要时加入第二人，尽量避免三人及以上对话。
- 不强制制造戏剧冲突。
- 结尾可作知识总结，也可提出相关问题，不强制互动。
- 面向实验室新手及有基础知识的观众，术语准确、表达通俗。

## 6. 如何要求修改

```text
保留已确认的产品事实和四项必需口播信息，
将开场改为直接点名产品，减少术语解释，
全片控制在 45 秒左右。
请同步更新大纲、时间线、可拍摄脚本和独立口播稿，
资料核验表保留对应来源。
```

修改时说明要改变的内容及必须保留的部分。不要只修改独立口播而忽略时间线和拍摄脚本的一致性。

## 7. 资料不足时如何处理

技能主动检索权威资料，优先核对具体产品资料、适用标准与权威数据库。来源放在核验表中，不混入口播正文，必要的安全条件仍须在口播中说明。

- 检索工具不可用时，会说明限制，不声称已联网核验。
- 产品参数不明确时，可补充品牌、货号或清晰标签。
- 不同来源有差异时，会区分等级、产品与适用条件。
- 必需口播事实尚未确定时，先解决缺口，或将输出明确标为待核实草稿。
- 混合物等不适用单一分子式或 CAS 时，说明不适用，不强行填写。

本说明是调用指南；具体执行规则以 [SKILL.md](./SKILL.md) 及使用者当前明确要求为准。
